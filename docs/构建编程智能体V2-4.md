
```Plain Text
↓
```

## F5 Shell / 命令执行

尤其注意：

```Plain Text
exit code != 0
```

通常**不等于 F7 的 Fatal Error**。

例如：

```Plain Text
pytest → 3 failed
```

这是一个非常有价值的正常 Observation。

Agent 正是要看到它，才能继续修代码。

**MVP 安全策略**

用户选择并提交 Workspace 后，视为授权 Agent 在该 Workspace 范围内执行完成编程任务所需的普通文件与命令操作。

F4 通过 `WorkspacePathGuard` 对文件访问路径进行规范化与边界检查，任何越出 Workspace 的文件访问均拒绝执行，并返回 `REJECTED ToolResult`。

F5 通过 `CommandSafetyPolicy` 判断命令是否允许执行，并通过 `WorkingDirectoryGuard` 保证命令工作目录位于 Workspace 范围内。普通测试、构建、运行等命令允许自动执行；危险命令直接拒绝，并返回 `REJECTED CommandResult`。

当前 MVP **不引入逐次用户确认 / Approval Workflow**。因此不增加 `WAITING_APPROVAL`、`APPROVED` 等额外 Runtime 或数据库状态。

`delete_file` 保持 Optional。

## F7 终止与错误处理

|事件 / 结果|是否进入 F7|类型|处理方式|
|---|---|---|---|
|**FinalAction**|❌|Normal Result|F6 保存 FINAL Message，将 AgentStep 置为 `COMPLETED`，生成 `AgentResult(COMPLETED)`|
|**Command exit\_code \!= 0**|❌|Standard Observation|F5 返回标准 CommandResult；F6 持久化结果，下一轮交给 LLM 继续处理|
|**File Error**|❌|Standard Observation|F4 将文件不存在、目标状态错误等标准化为 FileToolResult；F6 持久化后进入下一轮|
|**Tool Argument Error**|❌|Standard Observation|F4/F5 返回参数错误 ToolResult；F6 持久化后由下一轮 LLM 修正调用|
|**Command Timeout**|❌|Standard Observation|F5 返回 `TIMEOUT` CommandResult；F6 持久化后进入下一轮|
|**Command / Path Rejected**|❌|Standard Observation|F4/F5 返回 `REJECTED` ToolResult；F6 持久化后进入下一轮|
|**Search No Result**|❌|Standard Observation|F4 返回正常 ToolResult；F6 持久化后进入下一轮|
|**LLM API Timeout**|✅|Retryable RuntimeEvent|F7 根据 `retry_count` 返回 `RETRY`；达到 `MAX_RETRY` 后返回 `FAILED`|
|**Rate Limit**|✅|Retryable RuntimeEvent|F7 返回 `RETRY`；达到 `MAX_RETRY` 后返回 `FAILED`|
|**Temporary Network Error**|✅|Retryable RuntimeEvent|F7 返回 `RETRY`；达到 `MAX_RETRY` 后返回 `FAILED`|
|**InvalidAction / Invalid Response**|✅|Retryable RuntimeEvent|F7 返回 `RETRY`；达到 `MAX_RETRY` 后返回 `FAILED`|
|**ContextOverflowEvent**|✅|Terminal RuntimeEvent|F7 直接返回 `FAILED`，不进行 Retry|
|**Fatal Tool Runtime Error**|✅|Terminal RuntimeEvent|F7 直接返回 `FAILED`，不进行 Retry|
|**Fatal System / Unhandled Error**|✅|Terminal RuntimeEvent|F7 返回 `FAILED`|
|**Agent State Corrupted**|✅|Terminal RuntimeEvent|F7 返回 `FAILED`|
|**Infrastructure Error**|✅|Terminal RuntimeEvent|F7 返回 `FAILED`|
|**User Cancel**|✅|Runtime Condition|F7 返回 `CANCELLED`|
|**MAX\_STEPS**|✅|Runtime Condition|F7 返回 `TERMINATED`，`reason = MAX_STEPS`|
|**Loop Detected**|✅|Runtime Condition|F7 返回 `TERMINATED`，`reason = LOOP_DETECTED`|

```Markdown
    participant F6 as F6 AgentLoop / Agent循环
    participant F7 as F7 RuntimePolicy / 运行策略
    participant F8 as F8 PersistenceService / 持久化
    participant F2 as F2 ContextManager / 上下文管理
    participant F3 as F3 LLMGateway / 模型网关
    participant ROUTER as ToolRouter / 工具路由
    participant F4 as F4 FileTools / 文件工具
    participant F5 as F5 CommandTool / 命令工具


    Note over F6,F7: ① 每轮开始前检查 Runtime 控制条件

    F6->>F7: evaluate(state)
    F7-->>F6: RuntimeDecision

    alt FAILED / CANCELLED / TERMINATED

        Note over F6: 尚未创建新的 AgentStep
        F6-->>F6: 生成对应 AgentResult

    else CONTINUE

        F6->>F8: 创建 AgentStep(status=RUNNING)
        F8-->>F6: AgentStep


        Note over F6,F2: ② 构造 Context

        F6->>F2: build(task_id)
        F2-->>F6: Context / ContextOverflowEvent


        alt Context Ready

            Note over F6,F3: ③ 调用 LLM

            F6->>F3: invoke(context)
            F3-->>F6: AgentAction / RuntimeEvent


            alt FinalAction

                Note over F6: FinalAction 不经过 F7

                F6->>F8: 保存 ASSISTANT FINAL Message
                F6->>F8: AgentStep = COMPLETED

                F6-->>F6: 生成 AgentResult(COMPLETED)


            else ToolCalls[]

                F6->>F8: 保存 ASSISTANT Message

                loop 每个 ToolCall

                    F6->>F8: 创建 TOOL_CALLS(status=PENDING)

                    F6->>ROUTER: route(tool_call)

                    alt File Tool

                        ROUTER-->>F6: File Tool
                        F6->>F4: execute(tool_call)
                        F4-->>F6: FileToolResult / FatalToolRuntimeEvent

                    else Command Tool

                        ROUTER-->>F6: Command Tool
                        F6->>F5: execute(tool_call)
                        F5-->>F6: CommandResult / FatalToolRuntimeEvent
                    end


                    alt Standard ToolResult / Observation

                        Note over F6: 非零 exit_code / File Error / Argument Error<br/>Rejected / Timeout 等不经过 F7

                        F6->>F8: 更新 ToolCall 状态与结果

                        F6->>F8: 保存 TOOL_RESULT Message


                    else Fatal Tool RuntimeEvent

                        Note over F6,F7: Fatal Tool Error 不允许 Retry

                        F6->>F8: ToolCall = ERROR + fatal error

                        F6->>F7: evaluate(FatalToolEvent, state)
                        F7-->>F6: FAILED

                        F6->>F8: AgentStep = FAILED + error

                        F6-->>F6: 生成 AgentResult(FAILED)
                    end
                end

                F6->>F8: AgentStep = COMPLETED

                Note over F6: step_number + 1，进入下一轮


            else InvalidAction / Retryable LLM RuntimeEvent

                F6->>F7: evaluate(event, state)
                F7-->>F6: RuntimeDecision

                alt RETRY

                    F6->>F6: Backoff / retry_count + 1

                    F6->>F3: retry invoke(context)
                    F3-->>F6: AgentAction / RuntimeEvent

                    Note over F6: 再次失败则重新交给 F7

                else FAILED

                    F6->>F8: AgentStep = FAILED + error
                    F6-->>F6: 生成 AgentResult(FAILED)

                else CANCELLED / TERMINATED

                    F6->>F8: AgentStep = INTERRUPTED
                    F6-->>F6: 生成对应 AgentResult
                end
            end


        else ContextOverflowEvent

            Note over F6,F7: ContextOverflow 已完成所有本地压缩尝试<br/>当前 MVP 不进行 Retry

            F6->>F7: evaluate(ContextOverflowEvent, state)
            F7-->>F6: RuntimeDecision

            alt FAILED

                F6->>F8: AgentStep = FAILED + context overflow error
                F6-->>F6: 生成 AgentResult(FAILED)

            else CANCELLED / TERMINATED

                F6->>F8: AgentStep = INTERRUPTED
                F6-->>F6: 生成对应 AgentResult
            end
        end
    end
```

```SQL
    state "CANCELLED / 用户取消" as CANCELLED
    state "TERMINATED / 规则终止" as TERMINATED


    IDLE --> CHECKING : F1 run(task)


    %% 每轮开始
    CHECKING --> CONTEXT : CONTINUE
    CHECKING --> FAILED : FAILED
    CHECKING --> CANCELLED : User Cancel
    CHECKING --> TERMINATED : MAX_STEPS / Loop Detected


    %% Context
    CONTEXT --> LLM : Context Ready
    CONTEXT --> EVENT : ContextOverflowEvent


    %% LLM
    LLM --> ACTION : AgentAction
    LLM --> EVENT : Retryable LLM RuntimeEvent


    %% AgentAction
    ACTION --> FINISH : FinalAction
    ACTION --> TOOLS : ToolCalls[]
    ACTION --> EVENT : InvalidAction


    %% Tool
    TOOLS --> PERSIST : Standard ToolResult / Observation
    TOOLS --> EVENT : Fatal Tool RuntimeEvent


    %% 正常 Step 完成
    PERSIST --> CHECKING : AgentStep COMPLETED / Next Step


    %% RuntimePolicy
    EVENT --> RETRY : RETRY<br/>仅 LLM Retryable / InvalidAction

    EVENT --> FAILED : ContextOverflow / Fatal Tool / Fatal Runtime

    EVENT --> CANCELLED : CANCELLED

    EVENT --> TERMINATED : TERMINATED


    %% Retry 只重新调用 LLM
    RETRY --> LLM : Backoff 完成 / Retry LLM


    %% Final
    FINISH --> COMPLETED : FINAL Message + Step COMPLETED


    COMPLETED --> [*]
    FAILED --> [*]
    CANCELLED --> [*]
    TERMINATED --> [*]
```
